
**Система подбора кандидатов** — это веб-приложение для автоматизации работы отдела кадров. Приложение предназначено для HR-специалистов, рекрутеров и менеджеров, которым нужно удобное место для управления вакансиями и резюме соискателей.

## Основные возможности
* Управление вакансиями (создание, редактирование, удаление).
* База кандидатов с фильтрацией и поиском.
* Система откликов (связка кандидата с конкретной вакансией).
* Внутренние уведомления для сотрудников (Notification Service).

## 🚀 Установка и запуск

Данная инструкция поможет вам скачать проект с GitHub и запустить его на вашем компьютере.
Инструкция рассчитана на операционную систему **Windows**.

### 1. Установка необходимого ПО
Для работы проекта вам потребуется:
1. **Visual Studio** (Рекомендуется версия Community 2022). 
   * При установке обязательно выберите рабочую нагрузку **«Разработка ASP.NET и веб-приложений»** (ASP.NET and web development).
2. **.NET SDK** (обычно устанавливается вместе с Visual Studio, но можно скачать отдельно с официального сайта Microsoft).

### 2. Скачивание проекта
1. Нажмите на зеленую кнопку **`<> Code`** в верхней части этой страницы.
2. Выберите **`Download ZIP`**.
3. Распакуйте скачанный архив в удобную для вас папку.
*(Альтернативный вариант: клонируйте репозиторий через Visual Studio: Файл -> Клонировать репозиторий, вставив ссылку на этот проект).*

### 3. Запуск проекта
1. Откройте распакованную папку и найдите файл решения — он заканчивается на **`.sln`** (например, `Практика.sln`). Дважды кликните по нему, чтобы открыть проект в Visual Studio.
2. Дождитесь, пока Visual Studio загрузит проект и восстановит NuGet-пакеты (внизу будет идти полоса загрузки).
3. На верхней панели инструментов убедитесь, что выбрана конфигурация **`https`** (или `IIS Express`).
4. Нажмите зеленую кнопку **«Пуск»** (Play) на верхней панели или клавишу **`F5`**.
5. Приложение запустится, и в браузере автоматически откроется веб-страница с интерфейсом системы.

---
*Примечание: если при запуске возникнут ошибки, связанные с базой данных, проверьте файл `appsettings.json` и убедитесь, что на вашем компьютере установлен и настроен сервер баз данных (например, SQL Server).*
